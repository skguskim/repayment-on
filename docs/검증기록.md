## 실제 AI 대화 확인

기존 .env를 읽은 로컬 Node 서버에서 가상 대학생 사례로 OpenAI API를 호출했습니다. 키는 출력하지 않았고, 실제 사용자 재무정보는 사용하지 않았습니다. 최종 점검의 네 요청 모두 HTTP 200과 자연어 reply를 반환했으며, 3회 후속 대화의 응답 시간은 각 약 2.2~2.5초였습니다.

- “내가 이거 이번달에 절반 갚으면 어떻게돼?”: 월 납부액의 절반인지 입력 원금의 절반인지 확인하는 응답.
- “원금 90만원의 절반인 45만원을 예정 납부액에 더해 낸다”: 9월 예정액 15만원 + 추가 45만원 = 총 60만원, 월말 현금 70만원 → 25만원, 설정 기준 50만원 미달을 설명.
- “9월 말 최소 유지 잔액을 남기려면?”: 70만원 − 50만원 = 20만원의 월말 여유액을 설명.
- 일반 인사: 지원하는 질문이라는 분류 없이 대화형 응답.

개발 중 실제 응답에서 유지 기준과 예상 최저 잔액 혼동, 불명확한 절반의 임의 해석, 불필요한 원금·미래 납부액 추정이 관찰되었습니다. 이를 줄이기 위해 필드 이름을 구분하고 핵심 기준액을 지침에 전달하며, 한국어 지침을 간결하게 하고 확인 질문·월말 현금 중심 답변을 명시했습니다. 최종 점검에서는 핵심 현금 수치가 맞았지만, 후속 달에 대한 모호한 설명도 남아 있습니다. 소수의 성공 사례는 모든 응답의 정확성을 보장하지 않습니다. 답변 내용의 금융적 정확성을 전부 코드로 검증하는 구조는 아닙니다.

## 공개 배포 확인

https://repayment-on.checkdeep2025hanium.chatgpt.site 에서 로그인 쿠키와 인증 토큰 없이 앱 화면과 주요 파일이 정상 응답하는지 확인했습니다. `.env`와 서버 구현 파일은 404, 동의 없는 AI 질문은 400으로 차단됩니다. 대학생 가상 사례의 실제 AI 질문에는 9월 월말 현금 70만원에서 45만원을 추가 납부하면 25만원이 남는다는 답변을 수신했습니다.

Sites 배포 서버는 요청 한도를 D1에서 공유합니다. 데이터베이스에는 요청 식별자, 날짜별로 바뀌는 접속 IP의 HMAC 값, 요청 시각과 만료 시각만 기록하고 재무 입력·질문·답변 원문은 저장하지 않습니다. 기본 주소 외에 소유 확인을 마친 사용자 도메인을 허용하는 코드는 자동 테스트로 검증했으며, 별도 사용자 도메인의 DNS 연결은 완료하지 않았습니다.
