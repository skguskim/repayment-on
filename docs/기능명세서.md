# 상환ON 기능명세서

기준일 2026-09-07 / 현금흐름 계산 및 자연어 AI 대화

배포 주소: https://repayment-on.checkdeep2025hanium.chatgpt.site — 로그인 없이 이용할 수 있습니다.

## 화면과 계산

모바일 기준 최대 480px의 단일 열 화면입니다. 조건 입력 → 내 현금 흐름 계산하기 → 결과 확인으로 이동합니다. 조건 수정으로 돌아가면 입력값은 유지되며, 수정 후 다시 계산해야 새 결과로 질문하거나 보고서를 저장할 수 있습니다.

| 기능 | 동작 |
|---|---|
| 입력 | 가상 사례·직접 입력, 과거 일정 기간 자료의 중앙값 가져오기, 분석 기간 설정 |
| 현금 계획 | 시작 유동자금·최소 유지 잔액, 소득·생활비·기존 부채의 금액과 날짜 |
| 예정 소득 | 최대 12개, 확정/미확정, 일회/매월, 첫·마지막 지급월, 대체 소득·추가 지출 |
| 시나리오 | 기준 일정, 첫 입금 지연, 선택 소득 미발생, 미확정 소득 수령, 소득·지출 악화 |
| 대출 | 기존 부채의 월별 일정, 추가 원리금균등 상환과 총이자 |
| 결과 | 날짜별·월별 잔액, 부족 시점, 그래프 호버·탭·키보드 툴팁 |
| 보관 | 주요 조건과 결과를 담은 Markdown 보고서, 인쇄. 자동 저장 없음 |

금액은 화면에서 만원, 내부에서 원 단위 정수입니다. 계산 엔진은 같은 날 출금을 먼저 처리하고, 짧은 달의 납부일은 말일로 보정합니다. 추가 대출금은 현금에 더하지 않습니다. 중도상환, 수수료, 일할 이자, 법정 의무상환 계산은 지원하지 않습니다.

## AI 대화

정해진 질문 유형·근거 문장 선택·입력 변경 제안 기능을 제거했습니다. GPT는 현재 계산을 참고해 자연어로 답하며 입력값, 차트, 상환 일정은 변경하지 않습니다.

```text
조건 입력 → validatePlan → analyzePlan → 결과 화면
질문 + 최근 대화 + 현재 선택 상황 + 동의
  → POST /api/assistant
  → 입력·대화 형식 검증 → 현재 계획을 서버에서 다시 계산
  → 현재 계산 자료 + 대화 → OpenAI Responses API
  → {mode: "ai", reply: "자연어 답변"}
  → 사용자·AI 메시지를 대화창에 텍스트로 표시
```

- 질문은 최대 2,000자이며 주제 키워드로 거절하지 않습니다.
- 전송 내역은 최근 최대 4번의 완성된 문답, 합계 8,000자입니다. 시스템·도구 역할을 대화 내역으로 받지 않습니다.
- 계산 자료는 분석 기간·시작 현금·유지 기준, 소득·지출·부채 조건, 예정 소득의 이름·금액·상태·일정, 다섯 상황의 월별 결과, 선택 상황의 날짜별 입출금·예정 원리금 일정입니다.
- 과거 월별 원자료와 추가된 임의 필드는 OpenAI에 전달하지 않습니다.
- “절반 갚으면?”처럼 모호하면 무엇의 절반인지 확인하도록 안내합니다. 명확한 추가 납부 가정은 해당 월말 현금의 증감으로 설명합니다.
- 사용자 설정 최소 유지 잔액과 계산된 최저 잔액을 별도 필드로 전달합니다.
- 가정 설명은 새 계산 결과가 아닙니다. 모델의 수치·해석 전체를 자동 검증하지 않으며, 응답에 오류가 있을 수 있습니다.
- 입력 수정·재계산·다른 시나리오 선택 시 대화를 초기화하고 이전 요청 응답을 무시합니다.
- 동의 철회는 대기 요청을 취소합니다. 실패는 짧게 알리고 다시 보내기를 제공합니다. 가짜 AI 답변으로 대체하지 않습니다.
- 대화 지우기는 현재 브라우저의 내역을 지웁니다. 외부에 이미 전송된 기록을 삭제하지 않습니다.
- API 키·모델명·내부 식별자는 사용자 화면에 표시하지 않습니다.

## API와 실행

| 경로 | 방식 | 응답 |
|---|---|---|
| /api/status | GET·HEAD | 키 설정 여부·모델 설정·버전, 키 원문 제외 |
| /api/assistant | POST | 요청: plan, question, history, activeScenario, consent:true. 응답: mode, reply |

서버는 Origin·Host·명시적 동의·JSON 형식·48KB 요청 크기를 검사합니다. IP당 분당 6회, 전체 일일 100회, 동시 외부 요청 2회로 제한합니다. 서버 대기는 20초, 화면 대기는 25초입니다. 원문 질문·재무정보·키는 애플리케이션 로그에 기록하지 않습니다.

로컬에서는 Node 22.13 이상에서 `node server.mjs`로 실행합니다. `.env`의 OPENAI_API_KEY와 OPENAI_MODEL을 서버가 읽습니다. Sites 온라인 서버는 Cloudflare Worker에서 실행하며 D1에서 요청 한도를 공유합니다. `APP_ORIGINS`로 허용된 서비스 출처를 지정할 수 있습니다. 정적 시연본은 계산만 지원합니다.

## 시연과 검증

1. 대학생 사례에서 계산 버튼을 눌러 결과로 이동합니다.
2. 기준 잔액과 지연·미발생 시나리오를 비교하고 그래프의 월별 값을 확인합니다.
3. 기준 일정으로 돌아와 외부 AI 전송에 동의합니다.
4. “내가 이거 이번달에 절반 갚으면 어떻게돼?” → “예정 납부액 외에 45만원을 더 낸다는 뜻이야”처럼 대화합니다.
5. AI 답변 후 입력값·차트가 그대로 유지되는지 확인합니다.
6. 다른 시나리오를 선택하거나 다시 계산해 대화가 초기화되는지 확인합니다.

자동 검사와 실제 가상 사례 API 점검은 `검증기록.md`에 기록했습니다. 공개 URL의 화면·정적 파일·전송 동의·실제 AI 응답을 확인했습니다. 모든 기기의 시각적 배치와 광범위한 모델 정확도 평가는 별도 점검이 필요합니다.
