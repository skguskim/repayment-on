# 상환ON MVP v2

청년의 미래소득 지급일·종료일과 생활비·부채를 함께 계산하는 현금흐름 시뮬레이터입니다. 개정 기획서의 인턴 급여 지연 사례를 재현합니다. 대출 승인·한도·신용평가·수령 확률을 예측하지 않습니다.

**[배포된 서비스 바로 이용하기](https://repayment-on.checkdeep2025hanium.chatgpt.site)** — 회원가입이나 로그인 없이 접속할 수 있습니다.

## 실행

Node.js 22.13 이상에서 실행합니다. 로컬 서버·웹 앱은 별도 패키지 설치 없이 동작하며, 빌드와 자동 테스트에는 개발 의존성을 설치합니다.

```powershell
git clone https://github.com/skguskim/repayment-on.git
cd repayment-on
node server.mjs
```

기본 주소: **http://127.0.0.1:4173**

화면은 모바일을 기준으로 최대 480px의 단일 열로 표시합니다. 처음에는 조건 입력만 보이며, 생활과 소득 → 미래소득 → 상환 조건을 확인한 뒤 하단의 **내 현금 흐름 계산하기**를 누르면 별도 결과 화면으로 이동합니다. 결과의 **조건 수정**으로 돌아와도 입력값은 유지됩니다. 브라우저 뒤로가기·앞으로가기도 지원하며, 입력을 바꾼 뒤에는 다시 계산해야 결과를 볼 수 있습니다. 새로고침하면 입력값은 초기화됩니다.

Windows에서는 `run-local.ps1`로도 실행할 수 있습니다. 이 실행기는 서버를 별도 숨김 프로세스로 실행하고 기본 브라우저를 엽니다. 실행 창에서 Enter를 누르면 자신이 시작한 서버만 종료합니다.

## 구현한 기능

- 대학생·취업준비생·사회초년생 가상 사례, 직접 입력, 과거 일정 기간 자료의 중앙값 가져오기.
- 유동자금, 최소 유지 잔액, 필수 생활비, 유지할 선택지출, 비정기 지출 예산.
- 인턴·급여·상금·장학금: 확정/미확정, 일회/매월, 첫·마지막 지급월, 지급일, 대체 소득, 추가 지출.
- 기준 일정 / 첫 입금 지연 / 선택 소득 미발생 / 미확정 소득 수령 / 소득·지출 악화의 다섯 시나리오.
- 날짜별 잔액, 월말 잔액 그래프, 월중 최저 잔액, 첫 음수·최소 잔액 미달 날짜, 기간 이후로 이월된 입금.
- 그래프 호버·탭으로 월별 정확한 잔액과 기준 시나리오 비교. 키보드 좌우·Home·End로 월 이동, Escape 또는 바깥 터치로 툴팁 닫기.
- 기존 부채 월별 납부액, 추가 원리금균등 상환, 기간 종료·마지막 회차 정산·총이자.
- 현재 선택한 계산 결과를 참고하는 자연어 AI 대화와 후속 질문. 대화는 입력값·계산 결과를 변경하지 않습니다.
- 월별 잔액·시나리오 비교·주요 입력 조건을 담은 Markdown 보고서 저장, 인쇄용 스타일.
- 입력 변경 후 재계산 전에는 보고서·질문을 막고, 이전 입력에 대한 늦은 AI 응답을 무시.

## AI 활성화

기존 `.env` 설정을 서버 시작 시 읽습니다. API 키는 서버에서만 사용하며, 키가 없거나 연결에 실패하면 계산 기능은 계속 사용할 수 있지만 AI 답변은 제공하지 않습니다.

1. 저장소 루트의 `.env.example`을 `.env`로 복사합니다. `.env`와 실제 API 키는 Git에 포함하지 않습니다.
2. 로컬 편집기로 `.env`의 `OPENAI_API_KEY`를 입력합니다. **키를 채팅이나 프런트엔드에 붙이지 마세요.**
3. 필요하면 `OPENAI_MODEL`을 계정에서 접근 가능한 Responses API 지원 모델로 설정합니다. 기본 예시 모델은 `gpt-4.1-mini`입니다.
4. 서버를 재시작합니다. 환경에 이미 설정된 값이 `.env`보다 우선합니다.
5. 화면에서 외부 AI 전송 안내를 읽고 동의한 뒤 질문합니다.

```dotenv
OPENAI_API_KEY=본인_API_키
OPENAI_MODEL=gpt-4.1-mini
PORT=4173
HOST=127.0.0.1
APP_ORIGIN=
```

`OPENAI_API_KEY`는 유료 API 사용 자격 증명입니다. 프로젝트별 사용 한도·비용 알림을 계정에서 별도로 설정하세요. 키는 상태 API나 브라우저 코드로 반환하지 않습니다.

### AI가 하는 일

질문과 최근 대화 → 서버가 현재 계획을 다시 계산 → 선택 시나리오·월별 잔액·날짜별 내역·상환 일정 전달 → GPT 자연어 답변 순서입니다. 클라이언트가 보낸 임의의 계산 결과는 사용하지 않습니다.

정해진 질문 분류, 근거 ID, 변경 제안, 적용·취소·되돌리기 기능은 제거했습니다. 질문 때문에 입력값·차트·납부 일정이 바뀌지 않습니다. 예를 들어 “이번 달에 절반 갚으면?”의 대상이 불분명하면 확인 질문을 하고, “예정 납부액 외에 45만원을 더 내는 거야”라는 후속 질문에는 현재 계산을 바탕으로 현금에 미치는 영향을 설명합니다.

현재 시나리오의 결과와 과거 대화는 구분합니다. 입력 수정·재계산·다른 시나리오 선택 시 대화를 초기화하고 진행 중 요청을 취소합니다. 대화 지우기는 브라우저의 대화만 지우며 이미 외부로 전송한 정보를 삭제하는 기능은 아닙니다. 실패한 질문은 다시 보낼 수 있고, 이전 응답이 늦게 도착해도 변경된 화면에 표시하지 않습니다.

현재 브라우저에는 최근 20번의 문답을 유지하고, 요청에는 최근 최대 4번의 완성된 문답(합계 8,000자 이내)을 전달합니다. 한국어 조합 중 Enter는 전송하지 않으며, 일반 Enter는 전송, Shift+Enter는 줄바꿈입니다. 질문·답변은 HTML로 실행하지 않고 텍스트로 표시합니다.

챗봇의 가정 설명은 계산 엔진의 결과가 아닙니다. 중도상환 후 원리금 일정·총이자·미래 현금흐름을 새로 산출하지 않습니다. 프롬프트는 입력 원금과 실제 잔여 원금, 사용자 설정 최소 유지 잔액과 계산된 최저 잔액, 예정 납부액과 추가 납부액을 구분하도록 안내합니다. 자연어 답변의 모든 수치·해석을 프로그램으로 검증하는 구조는 아니므로 실제 모델 응답에는 오류가 있을 수 있습니다.

## 개인정보와 서버 보호

기본 계산은 브라우저 메모리에서만 이루어집니다. 자동 저장, 계좌 연결, 분석용 외부 추적 코드는 없습니다. 페이지를 새로고침하면 입력이 사라집니다. 사용자가 내려받은 보고서에는 재무정보가 있으므로 별도 관리해야 합니다.

외부 AI 전송 동의 후 질문할 때만 현재 계획·최근 대화를 서비스 서버로 전달합니다. OpenAI에는 질문과 최근 대화, 현재 선택한 시나리오, 분석 기간·시작 잔액·유지 기준, 소득·지출·기존 부채·추가 대출 조건, 예정 소득의 이름·금액·상태·일정, 계산된 월별 잔액·선택 상황의 날짜별 내역과 예정 원리금 일정을 전달합니다. 과거 월별 입력 전체와 허용하지 않은 임의의 입력 필드는 OpenAI에 보내지 않습니다. 서비스 서버는 원문을 파일·DB·애플리케이션 로그로 저장하지 않습니다. 호스팅 업체의 네트워크·접속 로그 정책은 별도로 확인해야 합니다.

OpenAI 요청은 `store:false`이지만 이것이 무보관을 뜻하지는 않습니다. 안전성 모니터링 로그는 기본적으로 최대 30일 보관될 수 있습니다. [공식 데이터 처리 안내](https://developers.openai.com/api/docs/guides/your-data)를 확인하세요.

서버는 정해진 정적 파일만 제공합니다. `.env`, 서버 구현, 테스트, 문서, 백업은 노출하지 않습니다. API는 동일 서비스 Origin·Host, 명시적 동의, JSON 형식, 48KB 요청 크기, 2,000자 질문 제한, 최대 8개 대화 메시지·합계 8,000자 제한을 확인합니다. 프로세스 메모리 기준으로 IP당 분당 6회, 전체 하루 100회, 동시 외부 요청 2회, 응답 대기 20초로 제한합니다. 프런트엔드는 25초 후 취소합니다.

로컬 Node 서버의 요청 한도는 프로세스 메모리를 사용합니다. Sites 배포 서버는 D1의 단일 SQL 문으로 입장을 제한해 여러 인스턴스에서도 분당 6회, 전체 하루 100회, 동시 2회를 함께 적용합니다. D1에는 무작위 요청 ID, 날짜별로 바뀌는 IP의 HMAC 값, 요청 시각과 만료 시각만 기록하며 재무 입력·질문·답변은 저장하지 않습니다. 이전 날짜의 기록은 새 요청 때 정리합니다. Origin 검사는 사용자 인증을 대신하지 않습니다.

## 계산 가정

- 날짜별 잔액 = 시작 유동자금 + 예정 유입 − 생활비·기존 부채·추가 원리금.
- 같은 날은 출금 우선. 29~31일이 없는 달은 말일로 보정합니다. 실제 입출금 시간은 알 수 없습니다.
- 월 생활비는 지정한 하루에 합산해 사용하는 가정입니다. 실제 일별 소비 예측은 아닙니다.
- 미래소득의 확정 상태는 사용자 진술이며 증빙을 자동 검증하지 않습니다. 용도가 제한된 돈은 자유롭게 쓸 수 있는 금액만 입력합니다.
- 첫 입금 지연은 **선택한 소득의 첫 회차만** 미룹니다. 다른 회차도 모두 밀리는 가정은 지원하지 않습니다.
- 미확정 소득은 기준에서 제외하고 기회 시나리오에서만 반영합니다. 확률 가중 기대소득을 만들지 않습니다.
- 대체 소득·추가 지출은 원래 활동월에 반영합니다. 활동월이 지급월과 다른 경우 이 MVP의 월 모델만으로 정확히 표현할 수 없으므로 입력 가정을 검토해야 합니다.
- 부채의 직접 납부 일정은 월별 금액과 공통 납부일을 사용합니다. 취업 후 상환 학자금대출의 법정 납부액을 산출하지 않습니다.
- 추가 대출금은 목적에 이미 사용된다고 가정해 잔액에 더하지 않습니다. 실제 수수료·일할 이자·거치·중도상환은 제외합니다.
- 계획 여유분과 배분율은 계획상 추가 상환 배분액에만 적용합니다. 여유분을 현금 잔액에서 이중 출금하지 않습니다. 일회성 수입은 정기 상환 배분액에서 제외합니다.
- 관측 개월 수·중앙값·분위수는 설명용 통계입니다. 학습된 예측 모형, 신뢰도 점수, 승인 한도, 부도확률이 아닙니다.

## 검증

실행에는 설치가 필요 없지만 DOM 테스트에는 개발 의존성 `jsdom`이 필요합니다. 잠금 파일은 `pnpm-lock.yaml`입니다.

```powershell
pnpm install --frozen-lockfile --ignore-scripts
node scripts/check.mjs
node --test
node scripts/build.mjs
```

테스트 종류는 계산 엔진, API 계약·보안, 로컬 DOM 단위 테스트입니다. DOM 테스트는 실제 브라우저를 열거나 외부 URL에 접속하지 않습니다. 자동 AI 테스트는 모의 응답입니다. 별도로 로컬 서버와 기존 .env를 이용해 가상 사례의 실제 API 대화를 점검했습니다. 이 소수의 점검은 전반적인 LLM 정확도 평가를 대체하지 않습니다.

현재 소스의 자동 테스트는 83개입니다. 공개 URL의 화면 응답·주요 파일·동의 검증·실제 AI 답변도 점검했습니다. 데스크톱·모바일의 모든 화면 배치와 실제 브라우저의 다운로드·인쇄 동작을 검증한 것은 아닙니다. 자세한 범위는 [검증 기록](docs/검증기록.md)을 참고하세요.

## 배포

### Sites 온라인 실행본

`pnpm build`로 기존 화면과 AI 서버를 함께 묶은 Cloudflare Worker를 만듭니다. 출력은 `dist/server/index.js`이며 `.openai/hosting.json`의 사이트와 D1 `DB` 연결을 사용합니다. API 키는 Sites의 비밀 환경변수 `OPENAI_API_KEY`, 모델은 `OPENAI_MODEL`, 실제 서비스 출처는 `APP_ORIGIN`으로 설정합니다. `.env` 파일과 원문 재무정보는 배포물에 포함하지 않습니다.

`APP_ORIGINS`에 쉼표로 구분한 정확한 주소를 지정하면 기본 배포 주소와 소유 확인을 마친 사용자 도메인을 함께 사용할 수 있습니다. 사용자 도메인은 Sites 연결 등록과 별도로 DNS 소유 확인 및 HTTPS 활성화가 필요합니다.

`db/schema.ts`와 `drizzle/`은 요청 한도용 테이블을 관리합니다. 새 스키마는 `pnpm db:generate`로 마이그레이션을 생성하고 배포 전에 검토합니다. 2026년 9월 7일 기존 75개와 온라인 서버 8개를 합친 자동 테스트 83개를 통과했습니다.

### AI를 포함한 Node 서버

`node server.mjs`를 실행하는 Node 22 이상 호스트를 사용하세요. `HOST=0.0.0.0`, 서비스가 지정한 `PORT`, `APP_ORIGIN=https://실제도메인`을 설정하고 API 키는 호스트 비밀 환경 변수에 저장합니다. `APP_ORIGIN`은 끝 `/` 없이 지정하며 요청의 Origin과 Host가 일치해야 합니다. HTTPS 종료 프록시는 원래 Host를 유지해야 합니다.

Dockerfile도 제공합니다. Docker 컨테이너의 빌드·배포는 별도로 검증해야 합니다.

```sh
docker build -t repayment-on .
docker run --rm -p 4173:4173 --env-file .env -e HOST=0.0.0.0 repayment-on
```
